[ 05 ]

使用方式

三种模式覆盖日常运维场景。

$ aist

进入连续对话，AI 会结合上一轮的命令输出继续分析。

$ aist "服务器负载很高，帮我排查原因"

一次提问即得到诊断建议，执行建议命令并完成本轮分析后退出。

$ tail -n 200 /var/log/nginx/access.log | aist "分析日志"

管道模式是只读的：只输出分析结果，不执行任何命令。

命令黑名单

黑名单会注入提示词，且命中命令在执行前直接拦截、不进入确认流程；尾部 * 匹配至少一个参数，无 * 时按前缀词匹配。

blacklist — config.yaml 
blacklist:
  - "rm *"               # 禁止带参数的 rm
  - "dd *"               # 禁止 dd
  - "kubectl delete *"   # 禁止 kubectl delete
  - "shutdown"           # 禁止 shutdown
  - "reboot"             # 禁止 reboot

操作审计日志

谁（账号、来源 IP）在何时对哪台目标服务器执行了什么命令（查询还是变更）、修改了哪个文件，人工确认、跳过还是拒绝，以及退出码与输出，全部记录在服务端审计日志中，可在管理后台按用户、主机、命令检索，满足事后复盘与合规审计。
